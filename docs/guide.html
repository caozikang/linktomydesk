简连 LinkToMyDesk 使用说明

开源的 Windows 远程控制软件。两台电脑都在内网也能连，用 9 位识别码加密码接入。

工作原理

控制端你面前的电脑，运行 RemoteControl.Client.exe
中继服务器一台有公网 IP 的服务器，只负责转发，不保存数据
被控端要被远程操作的电脑，运行 RemoteControl.Server.exe

两端都主动连接中继，所以不需要在路由器上做端口转发。中继要你自己部署一台，程序里没有内置公共中继。

在同一个局域网里，也可以不用中继，选「IP 直连」（默认端口 5900）。

1. 部署中继服务器

任意一台有公网 IP 的 Linux 或 Windows 服务器都可以，配置要求很低，1 核 1G 就够。

  1. 在服务器上安装 .NET 6 运行时。
  2. 把发布好的 publish-linux/RelayServer 目录上传到服务器，然后启动： 
    cd RelayServer
dotnet RemoteControl.RelayServer.dll 16888
    最后的数字是端口，不写默认就是 16888。
  3. 在服务器防火墙和云厂商控制台的安全组里，放行 TCP 16888。
  4. 想开机自动运行，可以用仓库里的 deploy-linux-service.sh 注册成 systemd 服务。
中继地址可以填域名或 IP，比如 relay.example.com。被控端和控制端要填同一个中继地址和端口。

2. 被控端

  1. 右键 RemoteControl.Server.exe，选「以管理员身份运行」。注入鼠标键盘需要管理员权限。
  2. 连接方式选「中继（推荐）」，填写中继服务器地址和端口。
  3. 点「开启远程协助」。底部显示「已连接中继节点」后，就可以接受连接了。
  4. 把卡片上的识别码和密码告诉对方，可以点 ⧉ 复制。点 ⟳ 会换一个新密码，已经连上的人不受影响。

接入选项

选项作用
对方确认后接入有人连接时弹窗询问，点「允许」才能接入。30 秒内没点就自动拒绝。
无人值守模式安装为系统服务，见 第 7 节。

「访问者」标签页显示当前谁在线、谁正在操作，「运行日志」标签页显示连接记录。

3. 控制端

  1. 运行 RemoteControl.Client.exe。第一次使用时，点右下角「设置」，填写中继服务器地址和端口。还可以填「我的名字」，多人访问时别人看到的就是这个名字。
  2. 输入对方的识别码（带不带空格都可以）和密码，按回车或点「连 接」。
  3. 如果对方开了「确认后接入」，会显示「等待对方点击允许」。
  4. 连接成功后进入远程画面，鼠标和键盘操作都会发给对方。

主页下方的「最近连接」会记住最近 8 台设备，点一下就能填好识别码，密码要重新输入。

4. 工具栏功能

画面上方有一条悬浮工具栏，鼠标移开后会变淡。

⠿ 左侧手柄按住拖动可以把工具栏移到画面任意位置，位置会记住。双击手柄，或者拖回顶部中间附近，就回到默认位置。
‹ / › 右侧箭头收起 / 展开工具栏。收起后只剩一个小条，不挡画面。
全屏进入或退出全屏。
原始尺寸在「自适应窗口」和「1:1 原始像素」之间切换。原始尺寸下可以滚动查看。
在线成员显示或隐藏右侧的成员和操作动态面板。
⇄ 传输文件打开文件传输窗口，见 第 5 节。
⌨ Ctrl+Alt+Del给对方发送 Ctrl+Alt+Del。需要对方开启无人值守模式，否则会提示无法发送。
✎ 白板标注开启后，在画面上按住拖动就能画线，所有在线的人和被控端屏幕上都看得到。右键清空全部标注。标注时不会操作对方电脑，再点一次退出标注模式。
● 录制开始或停止录制，保存为 MP4，放在「视频\LinkToMyDesk」文件夹。录制时底部会显示「录制中」。

延迟 · 速率往返延迟和当前接收速率。圆点颜色：绿色低于 80ms，黄色低于 200ms，红色更高。

会话中，除了在工具栏上，所有按键都会发给远程，包括 Tab、Alt、Win。但 Ctrl+Alt+Del 会被本机 Windows 拦截，发不出去，所以要用工具栏上的 ⌨ 按钮。

5. 文件传输

  • 点工具栏上的 ⇄，会打开一个双栏窗口：左边是本机，右边是远程。双击文件夹进入，Backspace 返回上一级，点路径栏旁边的 ⌂ 可以跳到桌面。
  • 选中文件（按住 Ctrl 可以多选），点中间的 › 上传到右边当前目录，点 ‹ 下载到左边当前目录。
  • 从资源管理器把文件拖到右栏可以直接上传。拖到远程画面上，会上传到对方桌面。
  • 底部的传输列表显示进度和速度，点 ✕ 取消。取消或失败后，传了一半的文件会自动删除。
  • 目标位置已有同名文件时不会覆盖，会自动改名为「文件名 (1)」。

6. 多人协作

同一台被控端最多可以 10 个人同时连接，大家看到的是同一块屏幕，都可以操作。

  • 右侧面板显示在线成员，每人一个颜色，正在操作的人后面标着「操作中」。
  • 「操作动态」会实时显示谁按了什么键、点了哪里。别人的操作还会在画面左上角浮动提示。
  • 有人正在按住鼠标拖动时，其他人的鼠标不会把指针抢走。
  • 每个人的画质和帧率各自独立，一个人网速慢不会拖慢别人。

7. 无人值守 / 锁屏解锁

普通模式下，被控端只是一个桌面程序。电脑锁屏、注销，或者弹出 UAC 窗口后，就看不到画面，也没法输入。开启无人值守后，程序作为 Windows 服务（以 SYSTEM 身份）运行，开机自动启动，这些情况下都能远程操作，还能发送 Ctrl+Alt+Del。

开启方法

  1. 以管理员身份运行被控端，不要加任何参数。
  2. 连接方式选「中继」，填好中继服务器地址和端口。无人值守只支持中继方式。
  3. 勾选「无人值守模式」，在弹窗里设置固定密码：8–32 位，同时有字母和数字，不能有空格。
  4. 程序会自动安装并启动服务。在服务列表（services.msc）里能看到「简连 LinkToMyDesk 无人值守」，服务名是 LinkToMyDeskService。从旧版（LinkDesk）升级时，旧服务会被自动清理。
  5. 被控端界面会变成只显示状态，底部显示「已连接中继节点 …（无人值守）」。之后关掉这个窗口也不影响远程连接。
注意：不要手动运行 RemoteControl.Server.exe --service。这个参数是给 Windows 服务管理器用的，手动运行只会弹一个提示，然后退出，不会安装服务，也不会接受连接。

远程解锁

  1. 用识别码和固定密码连接。无人值守模式下，原来的 6 位临时密码不能用了。
  2. 看到锁屏画面后，点工具栏上的 ⌨ 发送 Ctrl+Alt+Del。
  3. 输入 Windows 账号密码，就和坐在电脑前一样操作。

关闭方法

打开被控端，取消勾选「无人值守模式」并确认。服务会被停止并删除，固定密码也会一起清除。

运行日志在 C:\ProgramData\RemoteControl\agent.log，日志里不会记录密码。

画质与网络

档位分辨率码率（按 1080p）适合
流畅50%约 1 Mbps跨运营商、手机热点
标准（默认）75%约 2 Mbps大多数公网环境
高清100%约 4 Mbps带宽好的公网
超清100%约 8 Mbps局域网

卡顿时先降画质，再降帧率。延迟高通常是因为中继离两端都太远，或者跨了运营商，把中继部署在离双方都近的机房，效果最好。

常见问题

提示「设备不在线」或一直连不上

先看被控端底部有没有显示「已连接中继节点」。如果没有，检查中继地址、端口，以及服务器防火墙和安全组是否放行了 16888。另外确认两端填的是同一个中继。

能看到画面，但鼠标键盘没反应

被控端要以管理员身份运行。部分安全软件会拦截模拟输入，需要把程序加入白名单。

锁屏后画面卡住或变黑

普通模式下就是这样。要远程解锁，请开启 无人值守模式。

点 Ctrl+Alt+Del 提示「对方未开启无人值守模式」

只有系统服务才能发送这个组合键，需要先在被控端开启无人值守。

开了无人值守，但服务列表里没有服务

请确认是通过勾选「无人值守模式」开启的，而不是手动加 --service 参数运行。安装失败时，被控端会弹出原因，日志里也有记录。

多显示器时鼠标位置不对

先用工具栏上的「屏幕N ▾」切到要操作的那块屏幕，鼠标坐标是按当前这块屏幕计算的。

安全说明

  • 目前通信没有加密。跨公网使用敏感数据时，建议给中继加 TLS，或者在 VPN 里使用。
  • 密码只在被控端本地校验，中继不保存，也看不到密码。
  • 无人值守模式下，只要知道识别码和固定密码，任何人都能在没人看管时远程操作这台电脑，包括解锁。请使用强密码，不要告诉不信任的人。
  • 对不认识的人，开启「对方确认后接入」。
  • 请只在你拥有或已获得授权的电脑上使用本软件。
